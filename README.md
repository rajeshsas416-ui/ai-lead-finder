# AI Lead Finder

AI Lead Finder is an early stage project exploring how AI can help real estate professionals discover and qualify potential property buyer and seller leads.

## Project Vision

Finding genuine real estate opportunities is often fragmented across public listings, company websites, announcements, and other online sources.

AI Lead Finder aims to make this research process faster by helping users:

- Define the type of property opportunity they are looking for
- Discover relevant public information
- Organize potential buyer and seller leads
- Extract useful company and property context
- Reduce repetitive manual research

## Current Status

This repository is an early stage project and is under active development.

The product vision and architecture are being developed before production AI integrations are added. Features described as planned are not presented as currently available functionality.

## Planned Direction

The initial product direction includes:

1. Lead discovery from public web sources
2. AI assisted lead qualification
3. Structured lead profiles
4. Property and company context extraction
5. Search and filtering
6. LLM powered research summaries
7. A simple hosted web interface

## Technology

The implementation will evolve as the product is developed. AI and API integrations will be added only where they provide a clear product benefit.

## Development Principles

- Do not fabricate lead information.
- Clearly distinguish discovered facts from AI generated summaries.
- Respect website terms, robots.txt, rate limits, privacy requirements, and applicable laws.
- Never commit API keys, passwords, tokens, or other secrets.
- Prefer public and legitimately accessible information.

## Project Structure

The repository is intentionally starting with a small structure so the product architecture can evolve without unnecessary complexity.
