# Security Policy

## Reporting a Security Issue

Please do not publicly disclose API keys, credentials, tokens, private data, or other sensitive information.

If you discover a security vulnerability, report it privately to the project maintainer.

## Secrets

Never commit:

- API keys
- Access tokens
- Passwords
- Private keys
- Database credentials
- Session secrets

Use environment variables for local development and deployment secrets.

## Data and Lead Quality

AI Lead Finder is intended to work with legitimately accessible information. Users are responsible for complying with applicable laws, privacy requirements, website terms, robots.txt directives, and rate limits when collecting or processing external information.
