# Contributing

Thank you for your interest in AI Lead Finder.

## Development Guidelines

Before opening a pull request:

1. Keep changes focused.
2. Do not commit secrets or credentials.
3. Document meaningful architectural changes.
4. Do not claim functionality that has not been implemented.
5. Preserve the distinction between verified source information and AI generated content.

## Pull Requests

Please explain:

- What changed
- Why it changed
- How it was tested
- Any known limitations
